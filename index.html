斜率和速度，到底有什麼關係？

這張走時圖的橫軸是距離 x、縱軸是時間 t，因此斜率 m = Δt / Δx。若 t 用毫秒表示，v = 1000 / m（m/s）。斜率越小，速度越快。

波形圖的座標方向不同：時間在橫軸、距離沿縱向排列。請先看座標軸，再解釋斜率。不要直接連接各列的最高波峰；要比較同一類震波的第一到時。

WHEN A MODEL FAILS

遠處的波，為什麼比預測早到？

保留近距離的觀測，增加到 8、12 或 16 個感測器。若遠處的第一到時落在原本直線下方，原來的單一速度模型還足夠嗎？

觀察你看到的是「到時規律改變」，還是「所有震波突然變快」？

假說除了地下分層，時鐘誤差、橫向材料差異能否產生類似結果？

驗證從另一端敲擊、重複敲擊或延長測線，可以排除哪些解釋？

上層直達路徑經高速層的臨界折射路徑剖面比例依軸刻度；這是你提出的模型。
需要提示？認識臨界折射與模型假設

當水平下層的速度比上層快，震波可以在臨界角入射到界面，沿高速層頂部傳播，同時把波送回地表（首波／head wave）。遠處可能由這條路徑先到；近處通常由直達波先到。路徑較長，仍可能花較少時間。

直達波：t = x / v₁。臨界折射波：t = tᵢ + x / v₂；tᵢ = 2h cos(i꜀) / v₁；sin(i꜀) = v₁ / v₂。速度採 m/s 時，算出的 t 為秒。

臨界折射路徑只在 x ≥ 2h tan(i꜀) 時成立。交會距離 xcross = tᵢ / (1/v₁ − 1/v₂)，是兩路徑走時相等處；它與臨界距離不同。

此模型假設：地表平坦、地層水平、每層均勻、測點同步、比較同類波。若 v₂ ≤ v₁，本方法不會出現由高速下層造成的第二段首波直線。單一直線也不能證明地下沒有分層；較深界面或低速層可能尚未被辨識。兩段斜率支持速度分層的解釋，不能直接確定岩性或唯一地下構造。

教師備課／示範資料／科學與量測說明

15 分鐘試教：0–2 分鐘問題與預測；2–5 分鐘逐步加入 1、2、3、5 個感測器；5–8 分鐘標記第一到時與近距離速度；8–10 分鐘延長到 12 個感測器，檢查原模型；10–13 分鐘提出兩層模型、比較路徑；13–15 分鐘 CER 與 Exit Ticket。

固定的示範地下：v₁ = 300 m/s、v₂ = 900 m/s、h = 6 m。交會距離約 16.97 m，前五站（3–15 m）由直達波先到，18 m 起由臨界折射波先到。各階段使用同一地下，擴增感測器不會偷偷改變模型。

波形：以解析走時加上因果衰減振盪合成，含直達波與符合距離條件的首波；非完整彈性波場，未模擬反射、面波及真實儀器響應。背景雜訊可切換；第一到時提示是模擬真值，學生點選則有讀取誤差。

真實量測：應同步記錄並量測敲擊觸發時間；單純「開啟後等十秒」不保證毫秒級震源時間。未知敲擊時刻但站間同步時，站間到時差仍可估速度；厚度的截距時間解釋需要可靠的時間零點。3 m 間距與數十毫秒走時需要足夠取樣率、同步與耦合；一般低取樣率感測器不一定能完成這項量測。

教學實作：由教師操作敲擊，以適當敲擊板及現場規範布設，檢查噪音、接地耦合與訊號品質。五個感測器可透過分批移動延長測線，但要固定震源、同步觸發、重複敲擊並檢查每次的一致性；此網站延伸情境是新增同時同步的感測器。

評量：看學生是否能引用觀測、區分資料與假說、提出可檢驗預測、依新證據修正模型。不要只評分參數是否與示範值完全相同。
