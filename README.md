# 地下有什麼？震波探究實驗室

繁體中文互動教學網站。學生用 Prediction（預測）、Observation（觀察）、Explain（解釋）研究震波：先寫下想法，再看波形與第一到時，最後對照並修正地下模型。

## 檔案

- `index.html`：教學頁面與探究提示。
- `styles.css`：桌機、手機、列印版樣式。
- `app.js`：同步紀錄、合成波形、到時標記、走時分析、地下模型與路徑動畫。
- `TEACHER_GUIDE.md`：15 分鐘試教、探究提問、評量與原理解說。
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案。

不需要 npm、建置工具、API 金鑰、後端或外部 CDN。所有連結皆用相對路徑，可放在 GitHub Pages 專案子路徑。直接開啟 `index.html` 也可使用；本機檔案模式的瀏覽器儲存政策可能不同，請匯出學習紀錄保留文字。

## 部署到 GitHub Pages

1. 在 GitHub 建立 repository，例如 `seismic-inquiry`。
2. 解壓縮下載包，把 `index.html`、`styles.css`、`app.js`、`README.md`、`TEACHER_GUIDE.md` 與 `.nojekyll` 放在 repository 根目錄並提交。**根目錄要直接看到 `index.html`，不要多包一層資料夾。**
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
5. Branch 選 `main`，Folder 選 `/(root)`，按 **Save**。
6. 等待部署完成，開啟 Pages 顯示的網站網址；通常格式為 `https://你的帳號.github.io/seismic-inquiry/`。

若 repository 已有網站，可放到子目錄，再由既有 GitHub Pages 網址加上該子目錄名稱開啟。若已有 Actions 部署流程，請保持原流程，確定這些靜態檔案被一起發布。

官方說明：https://docs.github.com/en/pages/quickstart

## 操作

頁面分成三輪。每一輪都先預測，再觀察，最後解釋。

1. **第一輪｜近距離。** 先寫遠站會較早到、同時到，還是較晚到。再從 1 個感測器加到 5 個，每次配置改變後重新敲擊。相同測點的模擬到時不變。
2. 在放大波形的每一列，點「最早離開背景」的位置。表格也能用鍵盤輸入。看走時圖，寫下距離和到時的規律。
3. **第二輪｜新證據。** 先用近距離直線預測遠處到時，再延伸到 12 個感測器（也可選 8 或 16 個）。重新敲擊並標記新測站，比較觀察和預測。
4. **第三輪｜解釋模型。** 比較單一介質與水平兩層模型，調整速度與厚度，播放路徑競賽。修改模型不會改寫已記錄的波形。
5. 用主張、證據、推理寫下解釋，並完成模型限制、下一次檢驗與 Exit Ticket。下載到時 CSV 與完整 Markdown 探究紀錄。

「提示：標記模擬第一到時」顯示解析模型真值，適合示範與對照。學習紀錄會註記曾用提示。學習文字保存在目前瀏覽器，並非上傳到教師或跨裝置同步；教師可請學生繳交下載的檔案。

## 模型與數值

觀測示範固定使用水平兩層介質：上層 300 m/s、下層 900 m/s、上層厚度 6 m。敲擊點 0 m，感測器 3、6、9…m；同步取樣率 4,000 Hz（每 0.25 ms 一點）。紀錄第 10 秒敲擊，總紀錄 20 秒；動畫加速顯示時間流程。

每站的直達與有效臨界折射到時以解析式求得，再加上因果衰減振盪合成波形；背景雜訊可切換。它是原理模擬，未完整計算彈性波場、反射、面波、頻散、耦合與儀器響應。

- 直達走時：`t_d = x / v1`。
- 臨界角：`sin(ic) = v1 / v2`，需要 `v2 > v1`。
- 臨界距離：`xcrit = 2h tan(ic)`。只在此距離以外使用首波路徑。
- 截距時間：`ti = 2h cos(ic) / v1`。
- 折射走時：`t_h = ti + x / v2`。
- 第一到時：取有效路徑的較短走時。
- 交會距離：`xcross = ti / (1/v1 − 1/v2)`，約 16.97 m。

以上公式使用秒；圖表轉成毫秒。斜率以 ms/m 表示時，速度是 `1000 / slope`（m/s）。近站 3–15 m 由直達先到，18 m 起由首波先到。兩段回歸的分界預設 15 m，可由學生調整。厚度估算要求分段、水平介質與時間零點假設成立，不是對所有資料都適用。

低速下層、薄層、傾斜界面、橫向變化及量測誤差會造成辨識限制。兩段斜率不等於唯一地質答案，也不能直接確定材料種類。

原理參考：https://www.epa.gov/environmental-geophysics/seismic-refraction

## 維護

可在 `app.js` 的 `TRUE` 修改教師示範地下；若修改，請同步更新頁面的教師說明與本指南，並確認前五站仍是您想呈現的情境。`Physics.paths()` 處理有效路徑，`Physics.fit()` 計算線性回歸。

此版純靜態，沒有追蹤程式或網路資料請求。若瀏覽器支援 `document.modelContext`，可註冊選用的 `configure_sensor_count` 工具；一般瀏覽器不支援時不影響網站操作。

## 交付驗證

已通過 JavaScript 語法、HTML 檔案參照、解析走時與回歸數值檢查。三輪 POE 流程在瀏覽器中檢查過：敲擊、波形點選、到時提示、近距離斜率 300 m/s、延伸測線後保留預測直線、兩段回歸 900 m/s、厚度回算 6 m，以及桌機與手機寬度的版面。部署後仍請用你的瀏覽器再確認配置圖捲動、模型動畫與下載功能。

另提供 `seismic-inquiry-standalone.html` 單檔版，可直接開啟體驗；要用它部署，請改名為 `index.html` 放到 repository 根目錄。完整 ZIP 採分離檔案版，較適合後續修改。
